# Machine Learning from Scratch

A hands-on implementation of classic Machine Learning algorithms from scratch using Python and NumPy.

The main goal of this project is to understand how machine learning algorithms work internally by implementing their core logic step by step, rather than relying on high-level libraries such as `sklearn` for the model implementations.

The repository covers supervised learning, unsupervised learning, deep learning fundamentals, and basic searching algorithms. Each implementation is accompanied by practical examples, experiments, and visualizations where applicable.

## Algorithms

### Supervised Learning

* Linear Regression
* Logistic Regression
* Decision Tree (CART)
* Random Forest
* Naive Bayes
* Linear Support Vector Machine (SVM)
* K-Nearest Neighbors (KNN)

### Unsupervised Learning

* K-Means Clustering
* Principal Component Analysis (PCA)
* Apriori Algorithm

### Deep Learning

* Artificial Neural Network (ANN)
* Convolutional Neural Network (CNN)
* Recurrent Neural Network (RNN)

### Searching Algorithms

* Breadth-First Search (BFS)
* Depth-First Search (DFS)

## Approach

The implementations focus on the fundamental mechanics behind each algorithm, including:

* Mathematical intuition
* Core algorithmic logic
* Optimization techniques
* Distance and similarity calculations
* Probability and statistical concepts
* Model training and prediction
* Clustering and dimensionality reduction
* Visualization and experimentation

The goal is not to build production-ready replacements for established ML libraries, but to understand what happens behind the abstraction.

## Tools & Libraries

* Python

## Learning Goals

This project was created to:

* Build a deeper understanding of classic ML algorithms.
* Practice implementing algorithms without high-level ML frameworks.
* Connect mathematical concepts with actual code.
* Understand the steps involved in training and prediction.
* Develop stronger intuition about how different ML algorithms work.
* Experiment with algorithms using small and interpretable datasets.

## Disclaimer

This is an educational and experimental project. The implementations are intentionally simplified to make the underlying concepts easier to understand and are not intended to replace optimized production libraries.
